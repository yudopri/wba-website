# Sistem Informasi PT Wira Buana Arum

Aplikasi berbasis web yang dikembangkan untuk mendukung operasional PT Wira Buana Arum. Sistem ini digunakan untuk mengelola berbagai aspek bisnis seperti manajemen karyawan, keuangan, distribusi barang, serta stok gudang, dan dilengkapi dengan fitur company profile yang terintegrasi dengan sistem admin.

---

## Deskripsi Sistem
Sistem ini berfungsi sebagai platform terpusat untuk mengelola data dan aktivitas operasional perusahaan. Dengan adanya sistem ini, proses pengelolaan menjadi lebih terstruktur, efisien, dan mudah dipantau dalam satu aplikasi.

---

## Fitur Utama
- Manajemen data karyawan  
- Manajemen keuangan perusahaan  
- Manajemen distribusi barang  
- Manajemen stok gudang  
- Company profile (halaman publik perusahaan)  
- Dashboard admin untuk pengelolaan sistem  
- Pengolahan dan penyimpanan data secara terpusat  

---

## Teknologi yang Digunakan
- Backend: Laravel  
- Frontend: Blade, CSS, JavaScript  
- Database: MySQL  

---

## Peran dalam Pengembangan
- Mengembangkan backend dan frontend sistem  
- Membangun modul manajemen karyawan, keuangan, distribusi, dan gudang  
- Mengembangkan fitur company profile  
- Mendesain antarmuka pengguna (UI/UX)  
- Memimpin tim dalam proses pengembangan  

---

## Catatan
Sistem ini merupakan proyek privat yang dikembangkan untuk kebutuhan internal PT Wira Buana Arum.
